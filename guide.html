📖 User Guide

Learn how to use Uaskus Tweaker to optimize your Windows system

1 Run as Administrator

Uaskus Tweaker requires administrator privileges to modify system settings and apply optimizations.

  • Right-click on UaskusTweaker.exe
  • Select "Run as administrator"
  • Click Yes when prompted by User Account Control (UAC)

⚠️ Important

The program will not function correctly without administrator privileges. Always run as admin!

2 Navigate with Number Keys

Uaskus Tweaker uses a simple command-line interface. Use your keyboard's number keys to navigate through menus and select options.

1 Essential Tweaks (Recommended)
2 Performance Tweaks
3 Privacy Tweaks
4 Network Tweaks
5 Debloat Windows
6 Gaming Tweaks
0 Exit Program

3 Apply Tweaks

Once inside a category, you'll see a list of available tweaks. Press the corresponding number to toggle or apply each tweak.

  • Read the description of each tweak before applying
  • Some tweaks require a system restart to take effect
  • Press Enter to confirm your selection
  • Press B to go back to the previous menu

4 Restore Point (Recommended)

We highly recommend creating a system restore point before applying any tweaks. Uaskus Tweaker will automatically offer to create one for you when the program starts – just allow it when prompted!

  • When the program launches, it will ask if you want to create a restore point
  • Press Y to allow the program to create a backup automatically
  • This only takes a few seconds and can save you from potential issues
  • If something goes wrong, you can easily restore your system to its previous state

⚠️ Strongly Recommended

Always allow the program to create a restore point before making any changes. It's your safety net!

💡 Pro Tips

  • 🎮 For Gaming: Apply all tweaks in the "Gaming Optimizations" section
  • 🔒 For Privacy: Use "Privacy Settings" to disable telemetry
  • ⚡ For Speed: Combine "Performance Tweaks" with "Debloat Windows"
  • 💾 Always Backup: Create a restore point before making changes
