Desktop app guide

Use the app
with confidence.

This guide covers the current Uaskus Tweaker WPF application—not the earlier batch file.

01 Start with the right permissions

Right-click UaskusTweaks.exe and choose Run as administrator. Windows needs administrator permission for system-wide registry, service, network, and boot settings.

Admin is required for system changes

You can browse the app without elevation, but changes that need administrator access may fail. The title bar shows whether the app is running as admin.

02 Check what is already active

Use ↻ Check state in the category header. It reads applicable registry values and service start modes without changing anything.

ACTIVEEvery setting verified
PARTIALSome settings match
OFFSetting does not match
CHECK N/ACannot be verified safely

Some actions, such as flushing DNS or applying a one-time command, do not have a reliable persistent state. They intentionally show CHECK N/A instead of a guess.

03 Find and choose tweaks

Select a category in the left sidebar, or use the search box to filter the current category. Turn on only the tweaks you have read and understand.

⚙EssentialLower-risk starting points.
🔒PrivacyTelemetry and data-sharing controls.
⚡PerformancePower, visual, and responsiveness settings.
🎮GamingGaming-specific controls and services.

The risk badge is there for a reason: low-risk changes are generally easier to reverse, while high and critical changes need extra care.

04 Use a preset as a starting point

The Gaming, Privacy, Performance, and Extreme buttons in Quick Start select a group of relevant tweaks. They do not apply anything by themselves.

  • Choose a preset, then review its selected tweaks across the categories.
  • Deselect anything that does not fit your PC or how you use Windows.
  • Use Preview to read the selected list before applying it.

Be especially careful with Extreme

Extreme settings can affect power use, stability, compatibility, and startup behaviour. They are not recommended as a default setup.

05 Apply, verify, and restart if asked

Click Apply Selected in the bottom-right corner. The app creates a system restore point before applying your selected tweaks, then writes each result to the log panel.

  • Watch the log for successful and failed commands.
  • Use Export Log if you want to save a copy to your desktop.
  • Run Check state again when the operation completes.
  • Restart only when the app says a selected tweak requires it.

06 If something is not right

Use the Windows System Restore point created before the changes to return to an earlier state. If a change simply needs a reboot, restart first and check its state again.

A good rule of thumb

Apply a small group of changes at a time, especially on a gaming or work PC. It makes it much easier to identify and reverse a setting that does not suit your system.
