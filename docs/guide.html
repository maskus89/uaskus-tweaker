📖 User Guide

Learn how to use Uaskus Tweaker v2.0.0 WPF Edition to optimize your Windows system

1 Run as Administrator

Uaskus Tweaker requires administrator privileges to modify system settings and apply optimizations.

  • Right-click on UaskusTweaker.exe
  • Select "Run as administrator"
  • Click Yes when prompted by User Account Control (UAC)

⚠️ Important

The program will not function correctly without administrator privileges. Always run as admin!

2 Navigate the GUI

Uaskus Tweaker features a modern graphical interface. Use the sidebar to switch between tweak categories.

3 Apply Tweaks

Each tweak is displayed with a name, description, and risk indicator. Check the tweaks you want to apply, then click the Apply button.

  • Read the description of each tweak before enabling it
  • Some tweaks require a system restart to take effect
  • Use Select All to enable all tweaks in a category
  • Applied tweaks are shown in the built-in log panel

4 Restore Point (Recommended)

We highly recommend creating a system restore point before applying any tweaks. Uaskus Tweaker will automatically offer to create one when the program starts – just click Yes when prompted!

  • When the program launches, a dialog will offer to create a restore point
  • Click Yes to let the program create a backup automatically
  • This only takes a few seconds and can save you from potential issues
  • If something goes wrong, you can easily restore your system to its previous state

⚠️ Strongly Recommended

Always allow the program to create a restore point before making any changes. It's your safety net!

💡 Pro Tips

  • 🎮 For Gaming: Apply all tweaks in the "Gaming Optimizations" section
  • 🔒 For Privacy: Use "Privacy Settings" to disable telemetry
  • ⚡ For Speed: Combine "Performance Tweaks" with "Debloat Windows"
  • 💾 Always Backup: Create a restore point before making changes
